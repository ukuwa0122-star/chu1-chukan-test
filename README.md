# 中1・9月中間テスト対策 PWA

Macで `index.html` をブラウザで開くと使えます。学習記録はブラウザ内に保存されます。

## 問題・範囲の変更

`questions.js` に、英語と社会の問題がまとまっています。各問題には `id`、`unit`（単元）、`level`、選択肢、正解番号、解説があります。試験範囲表が届いたら、範囲外の問題を削除・置換し、必要な問題を同じ形で追加してください。

## GitHub Pagesで無料公開する手順

1. GitHubで新しいリポジトリ（例：`chugaku-test`）を作ります。公開設定は **Public** にします。
2. このフォルダ内のファイルをすべてリポジトリの一番上にアップロードします。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch を **main**、Folder を **/(root)** にして Save します。
5. 数分待つと表示される `https://ユーザー名.github.io/chugaku-test/` をiPhoneのSafariで開きます。
6. Safariの共有ボタン → **ホーム画面に追加** → **追加** を選びます。

公開後に問題を変更したら、同じファイルをGitHubで更新すれば、数分でサイトにも反映されます。iPhoneで古い表示のときは、アプリを一度閉じて開き直してください。

## 注意

記録は端末・ブラウザごとに保存されます。Safariのサイトデータを消すと記録も消えるため、大事な点数は別途メモしておくと安心です。
